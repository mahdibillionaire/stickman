# REACTION ASSETS FOLDER
=======================

Drop your 20 recorded reaction clips here:
- `react_01.mp4`
- `react_02.mp4`
...
- `react_20.mp4`

### Guidelines for Best Performance & Fair Use:
1. **Resolution**: Vertical (1080x1920) or Horizontal (1920x1080 / 1280x720) — the engine automatically scales and crops cleanly to the bottom 1080x960 box.
2. **Duration**: 40 to 60 seconds each.
3. **Gestures**:
   - Shocked / disbelief / jaw drop
   - Nodding / focused watching / pointing up
   - Cringing / covering mouth (great for medical/injury animations)
   - Laughing / smiling
4. **Voice Hooks**: In at least 4-5 clips, speak a quick 2-3 second reaction (e.g. "Wait for what happens next...", "Bro that is insane!", "No way that is real!"). This completely shields the channel against YouTube's "Reused Content" policy.
